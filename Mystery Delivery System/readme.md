Delivery Simulation System

This project is a simple Python-based delivery simulation system.
It assigns packages to the nearest delivery agent, simulates delivery routes, and generates performance reports.

Features
Load delivery data from a JSON file
Assign packages to the nearest agent
Calculate travel distances using Euclidean distance
Simulate package deliveries
Generate delivery performance reports
Export the best-performing agent to CSV

Files
main.py → Main program
data.json → Input delivery data
report.json → Generated delivery report
top_performer.csv → Best agent summary
