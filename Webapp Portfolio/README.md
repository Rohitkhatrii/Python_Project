# Developer Portfolio Website

A personal portfolio website built using Django, Python, HTML, and CSS to showcase projects, skills, and contact information through a clean and responsive interface.

## Features
- Multi-page website with Home, About, and Contact sections
- Featured Projects section to showcase development work
- Responsive and modern UI design
- Django template rendering and URL routing
- Reusable frontend components and structured layout

## Tech Stack
- Python
- Django
- HTML5
- CSS3

## What I Learned
- Full-stack web development fundamentals
- Django views, templates, and routing
- Frontend styling and responsive layouts
- Structuring scalable Python web applications
